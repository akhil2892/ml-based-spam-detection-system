Vocabulary is fitted on training data. Model settings and threshold are selected on validation data. The shipped model is evaluated on the held-out test split.

Know the boundaries

This benchmark covers English SMS, not every email or modern phishing attack. Similar templates may remain across splits. Scores are uncalibrated estimates; “not spam” never proves that a sender or link is safe.

Two TF-IDF vectorizers turn words, phrases and character fragments into features. A trained logistic regression model weighs them.

The spam score is compared with a validation-selected threshold. The UI shows actual features and their direction of influence.

{{ icon('spark') }}

AI is a second opinion. You choose when.

After a local check, you can explicitly allow a Gemini review. It can agree, disagree or be uncertain. Its response never changes the ML verdict, score or benchmark. Optional reply suggestions and neutral rewrites use the same consent.

No factual verification is claimed. If the API fails, your local detector keeps working.

About the project

Signal is an ML based spam detection system built with Python, scikit-learn and Flask. Training is reproducible from a credited public dataset. The full pipeline, evaluation report and tests are included in the repository.
